# DSA Foundations

## Data Structures

A data structure is a way to organize and store information so that it can be used efficiently.

Examples include:
- Lists
- Dictionaries
- Sets
- Stacks
- Queues
- Trees
- Graphs

## Algorithms

An algorithm is a clear, step-by-step procedure for solving a problem.

An algorithm works on data provided through a data structure and produces a result.

## How They Work Together

A data structure stores and organizes the information. An algorithm describes the steps used to process that information.

For example, a dictionary can store student records using student IDs as keys. The lookup procedure retrieves a record for a given ID.

## Understanding a Problem Before Coding

Before implementing a solution, identify:
1. **Input:** What information is provided?
2. **Output:** What result is required?
3. **Conditions:** What rules must be checked?
4. **Approach:** What sequence of steps can produce the result?

This separates understanding the problem from writing the code.
